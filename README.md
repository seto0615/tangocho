# Tangocho — 自分でつくる英単語帳

スクリーンショットやテキストに散らばった「英語＋日本語訳」をAIで読み取り、自分だけの単語帳にしてテストできるWebアプリ。スマートフォンのブラウザでそのまま動きます。

公開URL: https://seto0615.github.io/tangocho/

## できること

| 分類 | 内容 |
|---|---|
| 取り込み | AI読み取り（画像・PDFを Claude が解析し、英語と訳を対応づけ）／手入力／テキスト貼り付け・ファイル（.txt .csv .tsv） |
| 確認 | 取り込み前に一覧で確認・修正。登録済みの単語は自動で検出 |
| 単語帳 | 複数の単語帳、検索、絞り込み（★・苦手・未学習・学習中・習得）、並び替え、赤シート、発音の読み上げ |
| テスト | フラッシュカード（スワイプで仕分け）／4択クイズ／入力テスト。シャッフル、英→日・日→英・ミックス、範囲と出題数の指定 |
| 定着 | 正誤に応じて復習間隔が伸びる方式（1・2・4・7・14日）。「今日の復習」、連続日数、間違えた単語だけの再テスト |
| データ | 端末内に保存。JSONバックアップの書き出し・読み込み、CSV書き出し |
| その他 | ホーム画面に追加してアプリとして利用（PWA）、オフライン動作、ダークモード |

## AI読み取りの準備

1. [Anthropic Console](https://console.anthropic.com/settings/keys) でAPIキーを発行する
2. アプリの「設定」でキーを貼り付け、「接続テスト」を押す

キーはその端末のブラウザ内にだけ保存され、読み取りのときに Anthropic のAPIへ直接送られます。このアプリにサーバーはなく、開発者を含む第三者には送られません。API利用料は利用量に応じて発生します。

## 構成

ビルド不要の静的サイト（GitHub Pages で配信）。

```
index.html
css/style.css
js/app.js     画面と操作
js/store.js   保存・学習記録・統計
js/parse.js   テキストの自動分割（端末内で処理）
js/ai.js      Claude API での読み取り（公式SDKをCDNから読み込み）
sw.js         オフライン対応
```

ローカルで動かす場合:

```
python3 -m http.server 8765
```
